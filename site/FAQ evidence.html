Release boundaries supplied and verified by the catalogue owner: 13 February 2025, 7 August 2025, 19 February 2026, 2 July 2026; launch is the period before the first update. The selected rules period applies to lists and every performance calculation. Since includes the selected and later assigned periods; Only includes one assigned period. Unassigned events remain visible under All FAQ periods.

Confirmed: the event names an identifiable official FAQ release. Cutoff-based inference: an explicit rules publication cutoff determines the latest available release; adoption is inferred. Event-date estimate: the latest release available at the checked event start, without proof of adoption. Estimates are included in the filter and visibly labelled. Generic “latest FAQ”, community conventions, army-book release dates and list-submission deadlines alone do not confirm an official FAQ version. A date estimate never overrides ambiguous explicit official-version evidence.

Only cached event information, missing information pages and linked tournament documents were examined. Reviewed event decisions, list attribution and statistics exclusions were preserved. Source URLs, collection times, SHA-256 hashes, quotations and audit gaps are retained in the catalogue JSON and development evidence file.
